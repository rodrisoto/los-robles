# Sistema de Gestión de Medicación - Los Robles

Proyecto desarrollado para gestionar la administración de medicamentos en residencias de adultos mayores.

## Tecnologías
- Python
- Django
- HTML/CSS
- SQLite

## Funcionalidades
- Login de usuarios
- Dashboard de enfermería
- Control de dosis
- Gestión de pacientes
